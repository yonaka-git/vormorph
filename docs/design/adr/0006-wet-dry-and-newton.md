# ADR-0006: wet/dry を辺の水深で判定し、水位の連立方程式を修正量の形の Newton 法で解く

- 状態：承認
- 日付：2026-11-06

## 背景

ADR-0002 で、水位の連立方程式 $\mathbf{V}(\boldsymbol{\eta}) + \mathsf{T}\boldsymbol{\eta} = \mathbf{b}$ を Newton 法と PCG で解くことを決めました。実装にあたって、次の点が未決でした（[overview.md](../overview.md) の第8章）。

- 辺の水深 $H_j$ の細部：wet/dry の境界付近の扱い、$u_j = 0$ のときに使う水位
- Newton 反復の初期値と、収束が保証される条件
- 反復解法の収束判定値と、水の質量の保存との関係

検証ケース V03（干出する島を含む静水）と V04（汀線が動く振動）は、この3点の選び方で結果が変わります。

## 決定

### 辺の水深と wet/dry

- 辺の水深は $H_j = \max(\eta_{\mathrm{up}} - \max(z_{b,1}, z_{b,2}),\ 0)$ とします（ADR-0003）。風上側は $u_j^n$ の向きで決め、**$u_j^n = 0$ のときは両側の水位の高い方を使います**。
- $H_j$ が `dry_depth` 未満の辺は乾いた辺とし、$H_j = 0$、$u_j^{n+1} = 0$、重み $w_j = 0$ とします。
- **wet/dry の閾値は辺にだけかけ、セルの体積関数 $V_i = A_i\max(\eta_i - z_{b,i}, 0)$ には入れません。**
- **各ステップの最後に、乾いたセルの水位を河床高に揃えます**（$\eta_i \leftarrow \max(\eta_i, z_{b,i})$）。$V_i$ は変わらないので、水の体積には影響しません。

### Newton 法

- **修正量の形** $[\mathsf{P}^{(m)} + \mathsf{T}]\boldsymbol{\delta}^{(m)} = \mathbf{b} - \mathbf{V}(\boldsymbol{\eta}^{(m)}) - \mathsf{T}\boldsymbol{\eta}^{(m)}$ で解きます。
- $\mathsf{P}^{(m)}$ は $\eta_i^{(m)} \ge z_{b,i}$ のセルで $A_i$、それ以外で 0 とします（折れ点では右側の微分）。
- 初期値は $\boldsymbol{\eta}^n$ です。
- 収束判定は、乾いたセルを含む全セルで $\max_i \lvert r_i\rvert / A_i \le$ `newton_tol` とします。

## 理由

- **静水で偽の流れが出ない**：水面より高い乾いたセルは $\eta = z_b$ なので、湛水セルとの間の辺の水深は、高い方の水位 $z_b$ から高い方の河床高 $z_b$ を引いて 0 になります。$u = 0$ のとき両側の平均の水位を使うと、この辺の水深が正になり、乾いたセルの $\eta = z_b > \eta_0$ との水位差で偽の流れが生じます。
- **最初の Newton 段の係数行列が必ず正定値になる**：乾いたセルの水位を揃えるので全セルで $\eta^n \ge z_b$ となり、$\mathsf{P}^{(0)} = \mathrm{diag}(A)$ です。揃えないと（Casulli の元の形では乾いたセルで $\eta < z_b$ を許す）、孤立した乾いたセルの行が 0 になり、上流端から水が入るセルなどで係数行列が特異になります。出力の水位も意味のない値になります。
- **単調に収束する**：$\mathbf{V}$ が凸で、$\mathsf{P} + \mathsf{T}$ が M 行列なので、2段目以降の反復値は解以上にあり、単調に減少して有限回で収束します（[overview.md](../overview.md) の第4.3節）。
- **質量の保存が反復解法の精度で決まり、その精度が高い**：修正量の形では、PCG の相対判定値がその時点の残差にかかるので、Newton 反復が進むほど解の精度が上がります。$\boldsymbol{\eta}$ の形で解くと、相対判定値が $\mathbf{b}$（水の体積の大きさ）にかかるため、深い水域や大きな格子では、残差が `newton_tol` を下回らないことがあります。
- **負の体積を検出できる**：$V_i \ge 0$ は定義から常に成り立つので、「水深が負にならない」こと自体は何も保証しません。乾いたセルの残差も判定に含めれば、負の体積が必要な解（水を作り出さないと成り立たない解）は収束の失敗として検出されます。

## 代替案

### セルの水深にも閾値をかける

- 利点：ごく浅いセルの体積を 0 とみなせ、扱いが単純になります。
- 欠点：閾値以下の水が消えるので、水の質量が保存されません。河床変動の計算では、この誤差が積み重なります。

### $u_j = 0$ のとき両側の平均の水位を使う

- 利点：向きによらない対称な定義です。
- 欠点：上の「理由」のとおり、干出した島の縁で静水が保たれません。

### 乾いたセルの水位を揃えない

- 利点：Casulli (2009) の元の形に近く、ステップの最後の処理が要りません。
- 欠点：上の「理由」のとおり、係数行列が特異になる場合があり、出力の水位も意味を持ちません。

## 結果

- 静水は、干出する島があっても丸め誤差なしに保たれます（V03）。
- 水の体積の誤差は、反復解法の残差の水準になります（V04 で確かめる）。
- `vormorph` の出力では、乾いたセルの水位は河床高に等しくなります。
- `dry_depth` は辺の判定にだけ使います。閾値より浅い水は、乾いた辺に囲まれたセルに残ります（動かないが消えない）。
