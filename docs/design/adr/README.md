| 番号 | 題名 | 状態 | 日付 |

| [0002](0002-c-grid-semi-implicit.md) | C 格子と Casulli 型の半陰解法を採用する | 承認 | 2026-11-05 |
| [0003](0003-conservative-upwind-advection.md) | 移流を陽的な保存型風上差分で評価する | 承認 | 2026-11-05 |
| [0004](0004-rust.md) | 実装言語に Rust を採用する | 承認 | 2026-11-05 |
| [0005](0005-mesh-generator.md) | 格子生成は gmsh を使った自作ツールで行い、セルをヒルベルト曲線の順に並べる | 承認 | 2026-11-05 |

## 書き方

新しい ADR は次のひな形で作ります。一度承認した ADR は書き換えず、判断を変えるときは新しい ADR を作って古い方の状態を「置き換え（ADR-xxxx）」にします。

```markdown
# ADR-xxxx: 題名

- 状態：提案 / 承認 / 置き換え（ADR-yyyy）
- 日付：YYYY-MM-DD

## 背景

## 決定

## 代替案

## 結果
```
