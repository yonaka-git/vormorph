# ADR-0005: 格子生成は gmsh を使った自作ツールで行い、セルをヒルベルト曲線の順に並べる

- 状態：承認
- 日付：2026-11-05

## 背景

ADR-0001 では、任意の平面形の格子を JIGSAW（Engwirda, 2017）の局所直交格子で作る想定にしていました。導入を試みたところ、次の問題がありました。

- jigsawpy は PyPI で配布されておらず、C++ の本体をソースからビルドする必要があります（conda-forge には有り）。
- JIGSAW は独自のライセンスで、商用のシステムに組み込むには作者との取り決めが必要です。
- 境界の扱い（境界辺の母点と鏡映点の関係）を、Rust 側の規約（境界辺の `dc_edge` は鏡映点までの距離）に合わせて細かく制御したい。

あわせて、非構造格子ではセルの番号のつけ方で計算速度が変わります。番号の近いセルが空間的に離れていると、セル単位のループで隣のセルのデータを読むたびにキャッシュを外します。

## 決定

**格子生成ツール `tools/make_mesh.py`（Python パッケージ `tools/vormesh/`）を自作します。**

- gmsh（Geuzaine & Remacle, 2009）は、領域の境界（折れ線・円弧・穴）を格子幅で分割することと、内部に初期の母点を置くことに使います。
- ボロノイ格子は自前で作ります。境界辺ごとに、境界に関して対称な母点と鏡映点の対を置き（VoroCrust; Abdelkader et al., 2018 の考え方の2次元版）、境界の線分がそのままボロノイ辺になるようにします。内部の母点は Lloyd 法で重心ボロノイ分割（Du et al., 1999）に近づけます。
- **セルは母点のヒルベルト曲線（Hilbert, 1891）上の位置の順に並べます。** 頂点はセルの順に初めて現れた順に番号をつけ、辺も Rust 側で同じ規則で番号をつけます。
- ツールの出力は TOML の格子ファイル（vormorph mesh 形式 v1）とし、Rust 側は既存の依存（serde, toml）だけで読みます。ファイルには多角形の並びだけを入れ、接続配列と幾何量は Rust 側で組み立てます。

手順と形式の詳細は [docs/design/mesh-generation.md](../mesh-generation.md) にあります。

## 代替案

### JIGSAW（当初の想定）

- 利点：局所直交格子の生成に特化しており、球面にも対応します。格子幅の変化も滑らかです。
- 欠点：背景に書いた導入とライセンスの問題があります。境界の母点の置き方を自分で制御しにくい点も難点です。

### 領域で切り取ったボロノイ図（clipping）

母点のボロノイ領域を計算領域の多角形で切り取る方法です。最初はこの方法で実装しました。

- 利点：実装が簡単で、shapely などの多角形演算で済みます。
- 欠点：凹な角（島の角、合流部）の近くで、ボロノイ領域が角の裏側へ回り込み、母点から見えない飛び地ができます。鏡映点を足して防ぐと、今度は鏡映点の領域が角の反対側の計算領域に入り込みます。どちらも試して失敗したので、鏡映対の母点を境界に置く方法にしました。

### MPAS 型の切り落とし（culling）

広い範囲に格子を作り、領域の外のセルを捨てる方法です。

- 利点：すべての辺が厳密なボロノイ辺になり、境界の扱いが単純です。
- 欠点：境界が階段状になります。河岸の形を格子幅より細かく表せません。

### 三角形のセル（外心を計算点とする直交格子）

UnTRIM や D-Flow FM で使われている方法です。gmsh の三角形分割をそのまま使えます。

- 利点：格子生成が既存のツールで完結します。
- 欠点：ADR-0001 のボロノイ格子（多角形のセル）を変えることになります。鈍角三角形では外心が三角形の外に出るので、格子の直交化の処理が別に要ります。

### 番号のつけ方：行優先・Z 曲線（Morton 順）・RCM

- 行優先（x, y の辞書順）：直線水路では十分ですが、湾曲や島のある領域では隣のセルの番号が大きく離れます。
- Z 曲線：計算は簡単ですが、象限の境目で大きく飛びます。
- RCM（Reverse Cuthill–McKee）：行列の帯幅を小さくするので、直接法や不完全分解の前処理には有利です。この実装の水位の連立方程式は行列フリーの PCG（Jacobi 前処理）で解くので、帯幅より参照の局所性が効きます。
- ヒルベルト曲線：番号の連続した範囲が空間的にまとまった形になり、局所性と並列化の分割（rayon）の両方に使えます。

## 結果

- 境界の線分がボロノイ辺に一致し、境界辺でも直交性が厳密に成り立ちます。内部の辺の直交誤差は丸め誤差の程度（$\lvert\cos\rvert \sim 10^{-14}$）です。
- 凸な角は 90° 以上に限られます。格子幅は領域全体で一様です（局所的な細分化は今後の課題）。
- Python の後処理環境に gmsh・scipy・shapely が加わります。PyPI の gmsh は OpenGL と X11 の共有ライブラリ（Ubuntu では `libglu1-mesa`, `libxft2`）に依存します。
- gmsh は GPL-2.0-or-later（外部ライブラリとのリンクの例外つき）です。このリポジトリは gmsh を含まず配布もしないので、リポジトリのライセンス（MIT OR Apache-2.0）には影響しません。
- Rust 側では `mesh::voronoi::build`（多角形の並び → 接続配列）を、直線水路の生成と格子ファイルの読み込みで共通に使います。
- ADR-0001 の「格子生成には JIGSAW を使う想定」は、この ADR で置き換えます。
