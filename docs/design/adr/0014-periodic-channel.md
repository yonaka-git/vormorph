# ADR-0014: 直線水路に周期境界を加える（勾配を運動量式の体積力にし、継ぎ目の辺に平行移動を持たせる）

- 状態：承認
- 日付：2026-11-07

## 背景

交互砂州の検証ケース V09 では、交互砂州の線形安定解析（同じ式から求めた成長率と移動速度）と比べる計画です。交互砂州の不安定は移流型で、局所的な乱れは波群として下流へ流れ去ります（Federici & Seminara, 2003）。開境界の水路では、乱れが下流端から抜けてしまい、線形理論の時間成長と比べにくくなります。

開境界には、河床変動の段階でわかった性質もあります。

- 平衡給砂の給砂量は上流端の流れに追従するので、上流端の近くのセルの河床がほぼ固定されます（[ADR-0011](0011-edge-bedload.md)）。
- 給砂不足で河床が下がる幅の広い区間では、流路が分化します（[ADR-0013](0013-constant-sediment-supply.md)）。
- 六角形配置では、上流端のセルの母点の位置が行ごとに違うので、流量の配分がわずかに偏ります（V06、V12）。

そこで、直線水路の上流端と下流端をつなぐ周期境界を加えることにしました（作者と合意）。Nays2DH にも、交互砂州の計算のための周期境界条件があります（iRIC Project, 2023）。

## 決定

### 格子

- `mesh::channel::build_periodic` で、x 方向に周期 L の直線水路の格子を作ります。境界辺は側壁だけになります。
- 正方形配置は、今の配置のまま、x = 0 と x = L の境界辺を対にして継ぎます。
- 六角形配置は、母点を x 方向に周期的な三角格子にします。偶数行は今と同じ x = (i + ½)Δx、奇数行は x = iΔx（i = 0, …, n_x − 1）で、x = 0 の母点を加えます。
  - 各セルは、母点の周りの帯（側壁で切った矩形）を、近くの母点と、母点を ±L 平行移動した像との垂直二等分線で切り取って求めます。
  - 内部のセルはすべて同じ六角形になります。奇数行の x = 0 のセルは x < 0 にはみ出し、継ぎ目はジグザグになります。
- どのセルとも共有しない辺のうち、側壁にないものを継ぎ目の辺とし、`mesh::voronoi::connect_periodic` で、平行移動 (L, 0) で重なる対を内部の辺に継ぎます。
  - 継いだ辺は、上流端の側のセルの記録（頂点、中点、法線）を残します。
  - `Mesh::edge_shift`（新しいフィールド）に、下流端の側の母点を上流端の側から見た位置への平行移動 (−L, 0) を入れます。
  - 継ぎ目の頂点は両側に別の番号で持ちます。セルの多角形の面積と、VTK の出力に使うためです。
- 位置の差を使う計算は、`Mesh::edge_midpoint_from` と `Mesh::neighbor_position_from` を通して、セルの側の座標で行います。該当するのは、Perot 法（辺の中点）、河床勾配の最小二乗（隣の母点）、直交性の検査、`dc_edge` です。
- 縦断方向のセル数は 2 以上とします（1 だと、セルが継ぎ目の両側に来ます）。

### 流れと流砂

- 河床高 $z_b$ と水位 $\eta$ は、縦断勾配 $I$（`[bed] slope`）を除いた値で持ちます。実際の値は、それぞれに $I(L - x)$ を足したものです。こうすると、$z_b$ と $\eta$ そのものが周期的になります。
- 勾配は、運動量式の体積力 $g I n_{x,j}$ として $G_j$ に入れます（[overview.md](../overview.md) の第4.1節）。
  $\partial\eta/\partial n = (\eta_2 - \eta_1)/\delta_j - I n_{x,j}$ なので、θ 法の両方の時刻の項から、同じ定数 $g I n_{x,j}$ が出ます。
- 掃流砂の勾配の項は $(z_{b,2} - z_{b,1})/\delta_j - I n_{x,j}$ にします（第4.6節）。安息角補正の高低差には $I n_{x,j}\delta_j$ を戻します（第4.8節）。
- 設定は、上流端と下流端をともに `kind = "periodic"` にします。どちらか一方だけの場合、`[bed]` がない場合、構造物がある場合は、設定の誤りにします。
  - 上流端の `discharge` は、`Model::new` が初期状態を作るための流量です。初期状態は、河床高が一様に `z_downstream`、水深が $h_n = (nq/\sqrt{I})^{3/5}$、辺の流速が $(q/h_n)\,n_x$ の等流です。
  - 給砂と流出はなく、水と土砂の量は保たれます。計算中の流量は水の量と摩擦で決まり、河床が変わると変わります。
- `Model::with_state` は、周期境界の設定と周期的な格子（`Mesh::is_periodic`）が対応していなければ、組み立ての誤りにします。

## 理由

- **勾配を体積力にする**と、$z_b$ と $\eta$ が周期的になり、継ぎ目で値に段差がなくなります。
  - 継ぎ目の辺で値の差に段差 $IL$ を足す方法もありますが、差を取る所（辺の水深の風上の判定、辺の河床高、水位の連立方程式、運動量式、掃流砂の勾配、安息角補正、河床勾配の最小二乗）がすべて対象になり、足し忘れの危険が大きくなります。
  - 体積力にすると、手を入れるのは $G_j$ の1項、掃流砂の勾配の1項、安息角補正の1項だけです。
- **六角形配置を周期的な三角格子にする**のは、継ぎ目でも格子が乱れないようにするためです。
  - 今の切り取った端のセルを継ぐだけでは、継ぎ目に半分の大きさのセルの列が残ります。交互砂州を止めたり、乱れの種になったりするおそれがあります。
  - 周期的な格子では、どの行のセルも合同です（単体テストで確かめています）。
- **流量を制御しない**のは、線形理論の比較では流量の変化が2次の量で、実験の比較でも変化を記録すれば足りるためです。必要になれば、体積力を調整して流量を保つ形を加えます。

## 代替案

### 継ぎ目の辺で、水位と河床高の差に段差 $IL$ を足す

- 利点：$z_b$ と $\eta$ を、開境界の水路と同じ実際の値で持てます。辺の河床高 $\max(z_{b,1}, z_{b,2})$ も、開境界の水路と同じになります。
- 欠点：上の「理由」のとおり、手を入れる所が多くなります。勾配を除いた値で $\max$ をとる差は高々 $I\delta_j$（勾配 1/500、格子幅 1 m で 2 mm）で、等流では辺の水深が一致します（V06）。

### 六角形配置で、切り取った端のセルを継ぐ

- 利点：格子の生成が、正方形配置と同じ手順で済みます。
- 欠点：上の「理由」のとおり、継ぎ目に不規則なセルの列が残ります。

### 下流端の流量と流砂量の分布を上流端に渡す（擬似周期）

- 利点：格子の接続を変えずに済みます。
- 欠点：上流端と下流端の値の受け渡しが陽的になり、時間の遅れが入ります。水位の連立方程式も、両端でつながりません。

## 結果

- 周期 L の水路と、同じ初期状態を2回並べた周期 2L の水路を、移動床で 200 ステップ進めると、2L の水路の解は L の水路の解を2回並べたものに、丸め誤差（$10^{-16}$）の範囲で一致しました（`tests/periodic_channel.rs`。正方形配置・六角形配置）。継ぎ目は計算に跡を残しません。
- 単体テストで、次のことを確かめています。
  - 勾配を除いた一様な河床の等流の掃流砂量が $q_{b0}(1 + \gamma I)\,n_x$ になること
  - 安息角補正で、勾配のある水路と同じ量を動かすこと
  - 河床勾配の最小二乗が、継ぎ目のセルでも中心差分になること
- 検証ケースに、周期的な水路を加えました（結果は [verification.md](../../verification.md)）。
  - V01・V02：幾何と Perot 法の厳密さ
  - V06：静止状態から体積力で加速した流れが、等流の流速に $2\times10^{-11}$ で収束すること
  - V12：六角形配置でも平衡河床の変化が $10^{-14}$ m 以下（開境界の六角形配置では、上流端の流量の配分の偏りで 3.1 mm）
- 格子生成ツールの格子（`mesh.kind = "file"`）には、周期境界はありません。
