# ADR-0007: 開境界の水位を境界辺の上に置き、流量は断面で共通の水位から求めた通水能で配分する

- 状態：承認
- 日付：2026-11-06

## 背景

[overview.md](../overview.md) の第6章では、開境界を次のように決めていました。

- 下流端の水位境界：母点を境界辺に関して鏡映した点（鏡映点）の水位を既知とし、母点との距離に鏡映点までの距離 $\delta_j$（`dc_edge`）を使う。
- 上流端の流量境界：流量を通水能 $K_j = L_j H_j^{5/3}/n$ に比例して境界辺に配分する。$H_j$ の定義は未決。

検証ケース V06（等流）を実装したところ、どちらにも問題が見つかりました。V06 の条件は、延長 200 m・幅 20 m・勾配 1/500 の直線水路に流量 40 m³/s を与え、下流端の水位を等流水位に固定するものです。

1. **鏡映点に水位を置くと、等流が離散解にならない**：水面に勾配があるのに、鏡映点に1つの水位しか与えられないためです。六角形配置では、境界のセルごとに鏡映点の位置も異なります。中央部の水深の誤差は、格子幅 2 m（正方形・六角形配置）で 0.14%、1 m（六角形配置）で 0.069% でした（合格基準の案は 0.1%）。誤差は下流端で生じ、背水として上流へ伝わります（減衰の長さ $3h(1 - Fr^2)/(10I)$ ≈ 100 m）。
2. **各セルの水深で通水能を求めると、横断方向に不安定になる**：深くなったセルほど流入が増えてさらに深くなる、正のフィードバックが生じるためです。横断方向の流速は、丸め誤差（$10^{-15}$ m/s）から 100 s ごとに約 1000 倍に増え、数百秒で水深の誤差が 100% を超えました。幅1セルの水路では起きないので、横断方向に限った現象です。

## 決定

### 下流端（水位・水深）

- **与えた水位 $\eta_b$ を、境界辺の上の値とします。** 水位勾配は $(\eta_b - \eta_i)/(\delta_j/2)$ で評価します。$\delta_j/2$ は母点から境界辺までの距離です（`dc_edge` の半分）。
- 水深一定の境界では、$\eta_b = z_{b,i} + h_b$ とします（$z_{b,i}$ は内側のセルの河床高）。
- 辺の水深の風上は、流出なら内側のセルの水位、流入なら $\eta_b$、$u_j = 0$ なら高い方とします。河床高には内側のセルの値を使います。

### 上流端（流量）

- **通水能の水深を、断面で共通の水位 $\eta_s$ から求めます**：$H_j = \max(\eta_s - z_{b,i},\ $`dry_depth`$)$。
- $\eta_s$ は、上流端の湿ったセル（水深が `dry_depth` 以上）の水位を、辺の長さで重み付けして平均した値です。
- 配分は $Q_j = Q\,K_j / \sum_k K_k$、$K_j = L_j H_j^{5/3}$ です（粗度係数は辺によらないので比で打ち消し合います）。上流端のセルがすべて乾いていれば、辺の長さに比例して配分されます。

## 理由

- **等流が厳密な離散解になる**：境界辺の上に水位を置くと、等流の水面 $\eta(x)$ に対して $(\eta(L) - \eta(x_i))/(L - x_i) = -I$ が、母点の位置によらず成り立ちます。内部の辺でも、直交性と Perot 再構成により等流は厳密に成り立ちます（[overview.md](../overview.md) の第4.1節）。V06 では、中央部の誤差が $10^{-9}$ になりました（鏡映点では 0.14%）。
- **既存のモデルにも同じ選択肢がある**：D-Flow FM（Deltares, 2026 の Technical Reference Manual, §6.4.1）は、水位境界の仮想セルの中心を、鏡映の位置（`izbndpos = 0`、既定）か、境界辺の上（`izbndpos = 1`）から選べます。この決定は後者にあたります。
- **横断方向の不安定が生じない**：断面で共通の水位を使うと、配分は河床高の違いだけで決まり、セルの水深の揺らぎが配分に影響しません。D-Flow FM（同 §6.4.2.1、Algorithm 28）も、既定の設定（`jbasqbnddownwindhs = 0`）では、流量境界の辺の水深を「湿った境界セルの水位の重み付き平均 − 辺の河床高」とし、流量を $h^{2/3}A$（すなわち $L h^{5/3}$）に比例して配分しています。各セルの水深を使う設定（`jbasqbnddownwindhs = 1`）も用意されていますが、この決定では使いません。

## 代替案

### 鏡映点に水位を置く（従来の設計）

- 利点：境界辺も、内部の辺と同じ「母点間の距離」で扱えます。
- 欠点：上の「背景」のとおり、水面に勾配がある流れで O($I\delta_j$) の誤差が出ます。誤差は境界のセルの形によって変わります。

### 各セルの水深で通水能を求める

- 利点：水深が一様な等流では、配分が厳密に辺の長さに比例します。
- 欠点：上の「背景」のとおり、横断方向に不安定になります。

### 辺の長さだけで配分する（単位幅流量を一様にする）

- 利点：最も単純で、不安定も生じません。
- 欠点：断面内の河床高の違い（澪筋と高水敷など）を反映できません。

## 結果

- V06 の中央部の水深の誤差は $10^{-9}$ 程度で、合格基準を $10^{-4}$ に厳しくしました（鏡映点の場合の誤差 $10^{-3}$ を検出できる水準）。
- 六角形配置では、上流端のセルの母点の位置が行ごとに半間隔ずれるので、セルの河床高に $I\Delta x/2$ の差があり、その差が配分に入ります。格子幅 2 m の V06 では、上流端の近くに横断方向の流速 $10^{-3}$ m/s と、水深の誤差 $5\times10^{-6}$ が残ります（中央部には影響しません）。
- 水深一定の境界では、境界辺の河床高の代わりに内側のセルの河床高を使うので、勾配のある水路では O($I\delta_j/2$) の誤差が残ります。等流で確かめるときは水位境界を使います。
- `dc_edge` は、境界辺では引き続き鏡映点までの距離（母点から辺までの距離の2倍）として持ち、水位境界ではその半分を使います。
