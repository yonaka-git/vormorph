# ADR-0019: 二次流の強さを輸送方程式で求め、掃流砂の向きを内岸側へ回す

- 状態：承認
- 日付：2026-11-07

## 背景

湾曲した流れでは、遠心力で水面付近の水が外岸へ、河床付近の水が内岸へ向かう二次流（らせん流）が生じます。河床付近の流れが内岸へ向くので、掃流砂も内岸へ運ばれ、外岸が深く内岸が浅い横断形ができます。湾曲水路の検証ケース V10（外岸側の洗掘）には、この効果が必要です。

これまでの実装では、掃流砂の向きの基本を水深平均流速の向きにしていました（[overview.md](../overview.md) の第2.2節。河床近傍の流速 $\mathbf{u}_b$ を水深平均流速で代用）。二次流による補正は、第8章の未決事項でした。

決める必要があったのは次のことです。

- 二次流の強さの求め方：各時刻の流れで決まる平衡値を使う（平衡型）か、発達と減衰の遅れを表す輸送方程式を解く（輸送方程式型）か
- 流線の曲率（遠心加速度）の求め方
- 時間と空間の離散化、状態変数の持ち方、境界条件
- 掃流砂の向きの式と係数
- 二次流が運動量式に与える効果（分散応力）を入れるか

## 決定

作者と相談して、次のように決めました。

1. **輸送方程式型にします**（`[sediment.secondary_flow] kind = "transport"`。既定）。式は D-Flow FM（Deltares, 2026 の式 5.13〜5.20）と同じ形です（コリオリ力の項は除く）。

   $$
   \frac{\partial (hI)}{\partial t} + \nabla\cdot(\mathbf{q}\,I) = \nabla\cdot(hD\nabla I) + h\,\frac{I_e - I}{T_I}, \qquad I_e = \frac{h\,a_n}{\lvert\mathbf{u}\rvert}, \qquad T_I = \frac{L_I}{\lvert\mathbf{u}\rvert}
   $$

   $$
   L_I = \frac{(1 - 2\alpha)\,h}{2\kappa^2\alpha}, \qquad \alpha = \frac{\sqrt{g}\,n}{\kappa\,h^{1/6}}
   $$

   - 平衡型（$I = I_e$。$L_I \to 0$ の極限、Nays2DH の Engelund モデルに相当）も、比較用に `kind = "equilibrium"` で選べるようにします。
   - $\alpha \ge 1/2$（ごく浅い流れ。$n$ = 0.025 なら $h \lesssim$ 3 mm）では $L_I = 0$（平衡）とします。
   - カルマン定数 $\kappa$ は物理定数なので、`[physics] von_karman`（既定 0.41）で渡します。
2. **遠心加速度 $a_n$ は、流速の勾配から直接求めます。** 曲率を求めて $\lvert\mathbf{u}\rvert^3$ で割る形にはしません。

   $$
   a_n = \frac{\left(\mathbf{u}\times(\mathbf{u}\cdot\nabla)\mathbf{u}\right)_z}{\lvert\mathbf{u}\rvert}
   $$

   - $\mathbf{u}$ はセル中心の Perot 流速、勾配は最小二乗（`mesh::gradient::CellGradient`。2次の移流と同じ）です。
   - 左へ曲がる流れで正です（$a_n = \lvert\mathbf{u}\rvert^2/R$、$I_e = h\lvert\mathbf{u}\rvert/R$）。
3. **拡散係数は $D = \alpha_D u_\ast h$ とし、$\alpha_D$ の既定を 0.15 にします**（`diffusivity_coef`。浮遊砂の例と同じ形と値）。
4. **離散化**
   - セル中心の量として、浮遊砂（V08）と共用するスカラーの移流拡散 `transport` で解きます。
   - 移流は、連続式と同じ θ 平均流量の1次風上差分です。拡散は辺の2点差分で陽的に扱い、緩和の項は陰的に扱います。

   $$
   I^{n+1} = \frac{L_I\,I^\ast + \Delta t\,h\,a_n}{L_I + \Delta t\,\lvert\mathbf{u}\rvert}
   $$

   - $I^\ast$ は移流と拡散だけで進めた値で、$h$、$\lvert\mathbf{u}\rvert$、$a_n$、$L_I$ は時刻 $n+1$ の流れの値です。
   - 1ステップに1回、流れを進めた後（予測子・修正子では修正子の後）に解きます。河床変動を始める前（`morphology_start` まで）も毎ステップ解きます。
5. **状態には $hI$ ではなく $I$ を持ちます**（`State::spiral`）。
   - 時刻 $n$ の水深は、連続式を逆にたどって $h^n = h^{n+1} + (\Delta t/A)\sum_j s L q^\theta$ で求め、$A h^n I^n$ を保存量にします。
6. **汀線では $a_n = 0$ にします。** セルか隣のセルに乾いた内部の辺があれば、流速の勾配を使いません（2次の移流と同じ規則）。開境界の辺を持つセルは 0 にしません。
7. **境界条件**
   - 乾いたセルでは $I = 0$ です。
   - 上流端から流れ込む水の $I$ は 0、下流端は自由流出（逆流のときは内側のセルの値）です。
   - 壁と開境界の拡散の流束は 0、周期境界の継ぎ目の辺は内部の辺と同じです。
8. **掃流砂の向き**：河床付近の流速を $\mathbf{u} + \tan\delta\,(\mathbf{k}\times\mathbf{u})$ とし、その向きの法線成分を使います。$\tan\delta = N_\ast I/\lvert\mathbf{u}\rvert$ で、$N_\ast$ の既定は 7（Engelund, 1974）です。

   $$
   q_{b,j} = \sqrt{s g d^3}\;\Phi\left(\tau_{\ast j}\right)\left[\frac{u_j - \tan\delta_j\,u_{t,j}}{\lvert\mathbf{u}\rvert_j\sqrt{1 + \tan^2\delta_j}} - \gamma_j\,\frac{\partial z_b}{\partial n}\right]
   $$

   - $u_{t,j} = \mathbf{u}\cdot(\mathbf{k}\times\mathbf{n}_j)$ は、$\lvert\mathbf{u}\rvert_j$ と同じ平均の接線成分です。
   - 辺の $I$ は、両側のセルの平均（境界辺は内側のセルの値）です。
   - 掃流力の大きさは変えません。
9. **二次流が運動量式に与える効果（分散応力。D-Flow FM の式 5.33〜5.38）は入れません。** 第8章の未決事項に記録します。

## 理由

- **輸送方程式型**（作者の判断）：平衡型は、流線の曲率の局所的な特異点（澱みの近くなど）にそのまま反応します。また、湾曲部の出口から下流へゆっくり減衰する二次流を表せません。輸送方程式型は、適応長 $L_I$ の遅れで、どちらも自然に扱えます。
  - V09 の条件（$h$ = 1.07 m、$n$ = 0.025）では、$\alpha$ = 0.19、$L_I$ = 10.5 m です。格子幅 2 m の約 5 倍で、砂州の波長 211 m よりずっと短いので、ほぼ平衡に近い状態になります。
  - 実験水路（$h$ ≈ 0.1 m）では、$L_I$ は 2〜3 m 程度で、湾曲の長さと同程度になります。
- **勾配から直接求める**（作者の判断）：$a_n$ は流速と勾配の積で、$\lvert\mathbf{u}\rvert \to 0$ でも有界です。曲率 $1/R$ を経由すると、流れの遅い所で曲率が大きく振れます。
  - 緩和の項は $h\lvert\mathbf{u}\rvert(I_e - I)/L_I = (h^2 a_n - h\lvert\mathbf{u}\rvert I)/L_I$ なので、上の陰的な式は $\lvert\mathbf{u}\rvert$ で割りません。$L_I = 0$ の極限でも同じ式で平衡値になります。
  - Perot 流速は不規則な格子では1次精度で、その勾配は不正確になりうるので（D-Flow FM のマニュアル §5.6.2.1）、勾配は最小二乗で求めます。正多角形のセルでは、剛体回転の流れで $I_e = h\omega$ が丸め誤差まで一致します（単体テスト）。
- **$I$ を持つ**：河床の更新では湛水セルの水位を保つので（ADR-0012）、河床が変わると水深が変わります。$hI$ を持つと、河床を更新するたびに $I$ が $h_{\text{旧}}/h_{\text{新}}$ 倍にずれます。
- **$h^n$ を連続式から逆算する**
  - 流れの計算は、$V^{n+1} = V^n - \Delta t\sum s L q^\theta$ を Newton 法の残差の範囲で満たします。逆算した $h^n$ は、実際の値とその範囲で一致し、しかも移流の式と丸め誤差まで整合します。
  - そのため、$I$ が一様なら移流で一様なまま保たれます（単体テストでは、乾く所のあるこぶの上で 1e-11 以内）。時刻 $n$ の水深を別に保存する必要もありません。
- **1次風上**
  - 数値拡散（$\lvert\mathbf{u}\rvert\Delta x/2$。V09 の条件で約 1.9 m²/s）は、物理の拡散（0.023 m²/s）の約 80 倍です。
  - それでも $L_I$ が波長よりずっと短いので、砂州の波長で $I$ の振幅に効く量は 1% 未満と見積もれます。
  - 2次の再構成は、前進 Euler とは組み合わせられません（ADR-0016 と同じ不安定）。予測子・修正子と組み合わせる必要があるので、浮遊砂と合わせて第8章の未決事項にします。
- **陽的な拡散**：拡散数 $\Delta t\cdot 4D/\Delta x^2$ は、V09 の条件で約 0.02 です。$D/(\lvert\mathbf{u}\rvert h) \approx \alpha_D \sqrt{g} n / h^{1/6} \approx 0.015$ なので、格子幅が水深の数 % より大きければ、移流の条件より緩くなります。
- **掃流砂の向きの式**
  - Nays2DH（iRIC Project, 2023 の式 (67)(78)(85)）は、河床付近の速さを流線方向の成分で近似するので、分母の $\sqrt{1 + \tan^2\delta}$ がありません。
  - 正規化した形は、河床付近の流速の向きを厳密に回したもので、$\tan\delta$ が大きくても向きの成分の大きさが 1 を超えません。
  - 十分発達した湾曲で横断方向の掃流砂が 0 になる河床の横断勾配は、$\sin\delta = \gamma\,\partial z_b/\partial n$ です。$\delta$ が小さければ Engelund の関係 $N_\ast h/R = \gamma\,\partial z_b/\partial n$ に一致します。
- **汀線の $a_n$**：汀線のセルの Perot 流速は、乾いた辺を流速 0 として数えるので小さく出ます。その勾配から求めた $a_n$ は格子規模の大きさ（$\lvert\mathbf{u}\rvert^2/\Delta x$）になりえて、浅い所で $\tan\delta \sim N_\ast h/\Delta x$ の大きな偏角を作ります。開境界のセルを 0 にしないのは、二次流は流れに戻らないので、2次の移流のような正のフィードバック（ADR-0018）がないためです。
- **分散応力を入れない**（作者の判断）：まず掃流砂の向きだけで V09・V10 を確かめ、運動量式への効果が必要かどうかは、その結果で判断します。

## 代替案

### 平衡型だけにする（Nays2DH の Engelund モデル）

- 利点：輸送方程式を解く必要がありません。
- 欠点：湾曲部の出口の下流での減衰や、曲率の局所的な特異点を扱えません。比較用の選択肢としては残します。

### 流線の曲率を求めて、$I_e = h\lvert\mathbf{u}\rvert/R$ とする

- D-Flow FM の式 5.12 の形です。
- 欠点：流れの遅い所で $1/R$ が大きく振れます。

### 状態に $hI$ を持つ

- 浮遊砂の $hC$ と同じ持ち方です。
- 欠点：河床の更新のたびに $I$ がずれます（上の理由）。浮遊砂では $hC$（土砂の量）を保存するのが正しいので、共用の移流拡散は「保存量 $A h^n\phi^n$ を作って進める」形にし、どちらの持ち方でも使えるようにしました。

### 水深平均の渦度方程式から二次流を求める（細田ら, 2000。Nays2DH の非平衡モデル）

- 鉛直分布の仮定から係数が決まりますが、係数と項が多くなります。
- 輸送方程式型でも、遅れと減衰は適応長で表せるので、より簡単な D-Flow FM の形にしました。

## 結果

- `[sediment.secondary_flow]` を書かなければ、これまでと同じ計算になります。既存の検証ケースの値は変わりません。
- 単体テストで、次のことを確かめています。
  - 剛体回転の流れで $I_e = h\omega$ になる（正方形・六角形）。
  - 汀線では $a_n = 0$ になる。
  - 適応長の値が式どおりになる。
  - 一様流で、一様な $I$ が陰的な Euler 法の割合で減衰する。
  - 流入した値が $e^{-x/L}$ で減衰し、1次の収束をする。
  - こぶのある河床の上でも、一様な $I$ が保たれる。
  - 掃流砂が内岸側へ $\delta$ 回る。
  - 横断勾配 $\sin\delta/\gamma$ の河床が変わらない。
- 交互砂州の線形安定解析（`tools/bar_theory.py`）に二次流を加えて V09 で比べるのは、次の段階です。湾曲水路の V10 は、格子ファイルにセルの河床高を持たせた後に行います。
