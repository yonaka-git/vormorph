# ADR-0012: 河床の更新では、安息角補正を体積保存の Jacobi 型の反復で行い、湛水セルの水位を保つ

- 状態：承認
- 日付：2026-11-06

## 背景

[overview.md](../overview.md) の第4.8節では、Exner 式で河床を更新した後に、安息角補正と水位の調整を行うことだけを決めていました。

実装にあたって、次のことを決める必要がありました。

- 安息角補正で、複数の辺を同時に直すときの扱い、非侵食層との関係、反復を止める条件
- 水位を保つセルと、水深を保つセルの境目
- 体積の変化を、水と土砂の収支にどう記録するか

## 決定

### Exner 式と MORFAC

$$
(1-\lambda)\, A_i\left(z_{b,i}^{n+1} - z_{b,i}^{n}\right) = -M\Delta t\sum_{j\in\partial i} s_{i,j}\, L_j\, q_{b,j}
$$

- 流れを進めた後に、陽的に更新します（浮遊砂の項は、実装するまで 0 です）。
- 非侵食層の頭打ち（[ADR-0011](0011-edge-bedload.md)）で $z_b \ge z_{ne}$ は保証されています。丸め誤差の分だけ $z_{ne}$ にそろえます。

### 安息角補正

- 勾配が $\tan\phi$ を超える内部の辺で、その辺だけならちょうど $\tan\phi$ になる河床の体積の半分を、高い側から低い側へ移します。

$$
V_j = \omega\,\frac{\lvert z_{b,1(j)} - z_{b,2(j)}\rvert - \delta_j\tan\phi}{1/A_{1(j)} + 1/A_{2(j)}}, \qquad \omega = 0.5
$$

- 全辺を同時に評価する Jacobi 型です。1回の反復は次の4つのループです。
  1. 辺のループ：移す体積 $V_j$ を辺の配列に書く。
  2. セルのループ：高い側のセルから出る量の合計を、非侵食層より上の量 $A_i \max(z_{b,i} - z_{ne,i}, 0)$ で頭打ちにする倍率を求める。
  3. 辺のループ：流出側のセルの倍率を掛ける。
  4. セルのループ：集めて河床を更新する。
- 1回の反復で動いた厚さの最大値が粒径の $10^{-3}$ 倍未満になったら止めます。上限は 100 回です。上限に達したステップの数は、`vormorph run` の表示に出します（エラーにはしません）。
- 濡れたセルと乾いたセルの両方に、水中安息角を使います。

### 水位の調整

- Exner 式と安息角補正の後に行います。
- 水深が `dry_depth` 以上のセルでは、水位 $\eta$ を保ちます。河床が水面を超えたら $\eta = z_b$ とします（干上がる）。
- 水深が `dry_depth` 未満のセルでは、水深を保ちます（$\eta = z_b + h$）。
- 水の体積の変化 $\sum_i A_i (h_i^{\text{新}} - h_i^{\text{旧}})$ を `MassBalance::bed_exchange` に積算します。
- 土砂の収支（`SedimentBalance`）には、河床の土砂の体積の変化 $(1-\lambda)\sum_i A_i \Delta z_{b,i}$ と、境界の給砂量・流出量 $M\Delta t \sum L_j q_{b,j}$（地形の時間での体積）を積算します。

## 理由

- **体積が厳密に保存されます。** 移す量を辺の配列に1つだけ持つので、両側のセルが加える量は符号だけが違い、丸め誤差まで一致します（overview の「両側のセルが同じ式で計算する」と同じ結果になります）。どのループも、自分の値だけを書きます（CLAUDE.md の並列化の方針）。
- **緩和係数 0.5 にするのは、** 1つのセルが複数の急な辺に接するとき、全辺を同時に直すと行き過ぎるためです。
- **動いた厚さで判定するのは、** 床止めの下流面のように、高い側に土砂がない段差の勾配は直らないからです。勾配で判定すると、反復が止まりません。
- **湛水セルで水位を保つと、** MORFAC を掛けた河床の変化が、水面の擾乱として流れに入りません。水の体積を保つ（$\eta$ に $\Delta z_b$ を足す）と、河床の変化の分だけ水面が上下し、偽の波が生じます。保たない分の体積は収支に記録するので、水の収支は引き続き確かめられます。
- **ほぼ乾いたセルで水深を保つのは、** 河床が下がったときに水位を保つと、乾いた所に水が生じるためです。

## 代替案

### 安息角補正を1ステップに1回だけ行う（数ステップかけて緩和する）

- 利点：1ステップの計算量が一定です。
- 欠点：急な斜面が数ステップ残り、その間の流砂量の勾配補正が大きくなります。急な斜面がほとんどないときは、今の形でも反復は 0〜数回で済みます。

### 水の体積を保つ

- 上の「理由」のとおりです。

## 結果

- 単体テストで、次を確かめています。
  - 壁で囲んだ水域で、ランダムな河床と流れ（頭打ちと安息角補正が働く条件）から1ステップ進めても、土砂の総量が丸め誤差の範囲で保存されます。
  - 1セルだけ高い山は、勾配が $\tan\phi$ 以下になるまで崩れます。高い側が非侵食層の段差は崩れません。
  - 湛水・干上がり・ほぼ乾いた・乾いたセルの水位と、水の体積の変化
- 移動床の小さな水路（床止めを含む）で、土砂の収支の誤差が $10^{-12}$、水の収支の誤差が $10^{-10}$ 以下であることを、モデルの単体テストで確かめています。
