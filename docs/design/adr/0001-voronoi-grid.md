# ADR-0001: ボロノイ格子を採用する

- 状態：承認
- 日付：2026-11-05

## 背景

対象は、湾曲・合流・構造物（堰、床止め）を含む河道の平面二次元の河床変動です。格子には次の性質が必要です。

- 河道の平面形と構造物の位置に沿わせやすく、局所的に細かくできること
- 水位勾配と河床勾配を、余計な補正項なしに精度よく評価できること
- 長時間の河床変動計算に耐える計算効率があること

## 決定

**ボロノイ格子（母点を結ぶ線分と境界面が直交する非構造格子）を採用します。**

- 変数は C 格子に配置します（ADR-0002）。セル中心に水位・河床高・浮遊砂、辺に法線流速を置きます。
- 直交性があるので、辺の法線方向の勾配（水位勾配、河床勾配、濃度勾配）は2点差分 $(\phi_2 - \phi_1)/\delta_j$ で厳密に求まります。
- 接続配列は MPAS 形式（`cellsOnEdge`, `edgesOnCell`, `dcEdge`, `dvEdge`, `areaCell` など）に合わせます。既存の格子生成ツールや文献と対応を取りやすくするためです。
- 格子生成には JIGSAW（Engwirda, 2017）の局所直交格子を使う想定です。検証用には、直線水路の格子を内部で生成します（`mesh::channel`）。

## 代替案

### 一般曲線座標の構造格子

Nays2DH などの実用モデルで実績のある方式です。

- 利点：計算が速く、実装と後処理が単純です。河道に沿った座標をとれば、流下方向・横断方向の量を直接扱えます。
- 欠点：格子の非直交性による交差微分項が入ります。分岐・合流や構造物の周りで局所的に格子を細かくしにくいことも難点です。

### 非構造格子の有限体積法（セル中心配置）＋ Godunov 型の数値流束

HLL・HLLC・Roe などの近似 Riemann 解法を使う方式です。

- 利点：衝撃波（跳水・段波）を自然に扱えます。三角形格子で複雑な形状に合わせやすく、正値性や well-balanced 性の手法も多数あります。
- 欠点：多くは陽解法で、重力波の Courant 条件 $(\lvert u\rvert + \sqrt{gh})\Delta t/\Delta x \le 1$ に縛られます。構造物の周りの小さなセルで時間刻みが極端に小さくなるため、長時間の河床変動計算では計算量が問題になります。wet/dry と静水保持には静水圧再構成などの追加の工夫も要ります。

## 結果

- 2点差分の勾配と C 格子の組み合わせで、静水保持と質量保存を離散式の構造として保証しやすくなります。
- セル中心の流速ベクトル（流砂量や出力に必要）は直接得られないので、Perot 法で再構成する必要があります（`hydro::reconstruct_cell_velocity`）。
- 格子の品質（直交性・母点がセル内にあること）は格子生成の側に依存するため、格子の検査を検証ケース V01 に含めます。
- 外部の格子生成ツール（JIGSAW）との受け渡しの形式を別途決める必要があります（未決事項）。
