# ADR-0021: 流砂量式の有効掃流力に砂漣係数を掛ける（勾配補正の γ には掛けない）

- 状態：承認
- 日付：2026-11-08

## 背景

これまでの掃流砂量式は、流れの摩擦（マニング式）から求めた全掃流力 $\tau_\ast$ をそのまま使っていました（[overview.md](../overview.md) の第2.2節で「当面は $\tau_{\ast e} = \tau_\ast$」としていた箇所）。河床波（砂漣・砂堆）のある移動床では、摩擦の一部は河床波の形状抵抗で、砂粒を動かすのに効くのは残りの部分（有効掃流力）だけです。

検証ケース V10 で比べる DHL の湾曲水路の実験（Struiksma, 1983）は、粒径 0.45 mm の砂で河床波が発達した条件です。表1の T1（$\theta$ = 0.260、$C$ = 28.4 m^{1/2}/s）で素の MPM 式を使うと、流砂量は測定の約 7 倍になります。Struiksma は、MPM 式に砂漣係数を掛けた次の式（式 (1)）と測定を比べています。

$$
\Phi = 8\left(\mu\theta - 0.047\right)^{3/2}, \qquad \mu = \left(\frac{C}{C_{90}}\right)^{3/2}, \qquad C_{90} = 18\log_{10}\frac{12h}{D_{90}}
$$

ここで $\Phi$ は空隙を含まない無次元流砂量です（報告書の $\Psi$ と式 (1) は空隙込みで、$1/(1-\varepsilon)$ が付きます）。そこで、次のことを決める必要がありました。

- 砂漣係数を、定数で与えるか、局所の $C$ と $C_{90}$ から求めるか
- MPM 式と芦田・道上式のどこに掛けるか
- 長谷川の勾配補正の係数 $\gamma = \sqrt{\tau_{\ast c}/(\mu_s\mu_k\tau_\ast)}$ にも掛けるか

## 決定

- `[sediment.bedload]` に砂漣係数 `ripple_factor`（$\mu$、既定 1、$0 < \mu \le 1$）を加え、有効掃流力を $\tau_{\ast e} = \mu\tau_\ast$ とします。**定数**で与え、$D_{90}$ は設定に持ちません。
- **MPM 式**：$\Phi = 8(\tau_{\ast e} - \tau_{\ast c})^{3/2}$。限界との比較も $\tau_{\ast e}$ で行います（Struiksma, 1983 の式 (1)）。
- **芦田・道上式**：$\Phi = 17\,\tau_{\ast e}^{3/2}(1 - \tau_{\ast c}/\tau_\ast)(1 - \sqrt{\tau_{\ast c}/\tau_\ast})$。$\tau_{\ast e}$ は先頭の係数だけに使い、括弧の中と限界の判定は全掃流力 $\tau_\ast$ で行います。
- **勾配補正の $\gamma$ には掛けません**（全掃流力 $\tau_\ast$ のまま）。
- 上流端の平衡給砂は、内部の辺と同じ関数で求めるので、そのまま砂漣係数を含みます。二次流の拡散係数など、流れの摩擦速度を使う量は変えません。
- $\mu = 1$ なら $\mu\tau_\ast = \tau_\ast$ が丸め誤差なしに成り立つので、既存の計算と検証ケースの値は変わりません。

## 理由

- **Struiksma の定義どおりの式にします。** 報告書の表1には $\mu$ も $D_{90}$ も載っていません。図2の粒度曲線から $D_{90} \approx$ 0.6 mm と読み、表1の $C$ と $h$ で求めると、$\mu$ は T1 で 0.346（$\mu\theta$ = 0.090）、T2 で 0.337（$\mu\theta$ = 0.091）です。図3の DHL の点（$\mu\theta \approx$ 0.09）と一致します。
- **定数で十分です。** マニングの $n$ が一定なら、局所の $C = h^{1/6}/n$ と $C_{90}$ から求めても、T1 の水深 0.05〜0.12 m で $\mu$ は 0.339〜0.353 と 4% しか変わりません。$D_{90}$ と水深による変化を持ち込まずに済みます。
- **測定の流砂量に合わせて当てはめた値は使いません。** 上の $\mu$ でも、MPM 式は測定の 0.63 倍（T1）・0.69 倍（T2）です（報告書も一致は悪いとしています）。測定に合わせるには $\mu$ = 0.41・0.38 が必要ですが、これは報告書の定義ではなく、こちらの当てはめになります。平衡給砂で求める平衡地形は、流砂量の大きさではなく、$\Phi$ の $\tau_\ast$ への依存（指数 $b = 1.5\,\mu\tau_\ast/(\mu\tau_\ast - \tau_{\ast c})$。T1 で $\mu$ ありなら 3.1、なしなら 1.8）と $\gamma$ で決まります。大きさが変えるのは、平衡に達するまでの時間だけです。
- **芦田・道上式の形**は、原著と Nays2DH マニュアル（iRIC Project, 2023 の式 (59)）のとおりです。原著は有効掃流力を独自の抵抗則から求めていますが、ここでは同じ位置に $\mu\tau_\ast$ を入れます。
- **$\gamma$ には掛けない**のは、Nays2DH（式 (69)）が全掃流力 $\tau_\ast$ を使っているのと同じ扱いで、流砂量の大きさだけを補正するためです。

## 代替案

### 局所の $C$ と $C_{90}$ から砂漣係数を求める

- 利点：水深による違いを表せます。
- 欠点：設定に $D_{90}$ が増えます。上の見積もりのとおり、効果は 4% 程度です。

### 勾配補正の $\gamma$ にも砂漣係数を掛ける

- 利点：砂粒に働く流体力と重力の比という $\gamma$ の意味からは、有効掃流力を使うほうが一貫しているという見方もあります。
- 欠点：Nays2DH と扱いが変わります。

V10 の条件（T1）で十分発達した湾曲の横断勾配 $N_\ast h/(R\gamma)$ を見積もると、$\tau_\ast$ のままなら 0.074（$\gamma$ = 0.63）、$\mu\tau_\ast$ にすると 0.043（$\gamma$ = 1.08）です。測定から読んだ横断勾配は、ポイントバーの付近（CS10）で約 0.05、湾曲の後半（CS25）で約 0.02 なので、掛けないと横断勾配が急に出るおそれがあります。$\gamma \propto 1/\sqrt{\mu_s\mu_k}$ なので、`kinetic_friction` を $0.45\mu$ にすれば「掛けた」のと同じ計算が、新しい設定なしでできます。V10 では、これで $\gamma$ を振った感度を示し、結果によってはあらためて ADR で扱いを決めます。

### 測定の流砂量に合うように砂漣係数を決める

- 上の「理由」のとおりです。

## 結果

- 砂漣係数を省略した設定は、これまでと同じ計算になります。
- 流砂量式の関数 `sediment::formulas::bedload_intensity` は、全掃流力と砂漣係数を受け取る形になりました。芦田・道上式の関数は、有効掃流力と全掃流力の両方を受け取ります。
- 単体テストで、MPM 式の限界の判定が $\mu\tau_\ast$ で行われること、芦田・道上式は先頭の係数だけが $\mu^{3/2}$ 倍になること、等流の辺の流砂量の手計算（$\gamma$ は $\tau_\ast$ のまま）、設定の既定値と範囲の検査を確かめています。
