# ADR-0018: 2次の移流は、開境界の辺を持つセルで1次に戻す

- 状態：承認
- 日付：2026-11-07
- [ADR-0016](0016-second-order-advection-ssp-rk2.md) の2次の再構成に、境界の扱いを加える

## 背景

既定の移流を2次（ADR-0016）、時間積分を予測子・修正子（[ADR-0017](0017-predictor-corrector.md)）に切り替えて、例題 `examples/sill.toml` を計算したところ、t ≈ 2.1 s で水位の連立方程式の PCG が破綻しました（pᵀAp ≤ 0）。1次の移流では、同じ予測子・修正子でも問題なく進みます。

- この例題は乾いた河床から始まり、下流端の水位境界（1.07 m）から水が流れ込みます。
- 下流端の境界の辺で、内側のセルの水位が境界の水位より高いのに、流入速度が増え続けました（t = 1.65 s の −7.1 m/s から、t = 2.07 s の −40 m/s へ。時間刻みは可変なので 0 に近づいた）。
- 境界の辺の移流の増分（F u − u）が、流入を加速する向きでした。

ADR-0016 の形では、境界のセルの流速の勾配を内側の隣のセルだけから求めます（片側の差）。辺の流速を、セルの流速を辺まで外挿した値 ũ へ近づける項と、そのセルのほかの面の値を通して、境界へ向かって大きくなる流速の傾きが外挿で強められ、正のフィードバックになっていました。これまでの検証ケースでは、開境界は流出（V06・V07）か流量境界だったので、現れませんでした。

## 決定

**上流端・下流端の辺を持つセルでは、流速の勾配を 0 にします**（`hydro::advection_second_order`。汀線のセルと同じ扱い）。

- 境界のセルの移流は1次の形（ADR-0009）になり、境界の辺の更新は、その辺の流速と流れ込む水の流速の凸結合に戻ります。
- 壁の辺は数えません。壁ぎわのセルは、これまでどおり片側の勾配を使います（V09 の周期的な水路の側壁など）。
- 周期境界の継ぎ目の辺は内部の辺なので、継ぎ目のセルも2次のままです。

## 理由

- 開境界の外側の流速は分からないので、片側の勾配で外挿しても精度は上がりません。境界の流量や水位は境界条件で与えるので、境界のセルを1次にしても、内部の2次の精度への影響は境界の近くに限られます。
- 辺ごとに外挿だけを止める形（境界の辺では ũ = U_c）も試しました。下流端の破綻は t = 6.6 s まで延びましたが、側壁の角に近い境界の辺で同じように流入が加速して破綻しました。そのセルのほかの面の値が、片側の勾配を使っていたためです。
- `model` の単体テストで、`examples/sill.toml` の最初の 10 s を計算し、流速が有界で水の収支が合うことを確かめています（勾配を 0 にしないと t ≈ 2 s で 20 m/s を超える）。

## 代替案

### 境界の外側に、境界条件から鏡映した値を置いて勾配を求める

- 水位境界の外側の流速は境界条件で決まっていないので、置く値に任意性が残ります。

### 結果を範囲に収める（制限する）

- ADR-0016 で退けたとおり、跳水の釣り合いが崩れ、ダム破壊の収束が止まります。

## 結果

- 既定の設定で `examples/sill.toml` を最後まで計算できるようになりました（[verification.md](../../verification.md)）。
- 開境界のある検証ケース（V06・V07・V11・V12）の値は、境界の近くでわずかに変わります。値は verification.md に記録しました。
