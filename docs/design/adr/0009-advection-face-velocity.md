# ADR-0009: 移流では、辺の流速そのものを上流の流速へ近づける

- 状態：承認
- 日付：2026-11-06
- [ADR-0008](0008-advection-discretization.md) の一部（移流の「自分の流速」）を置き換える

## 背景

ADR-0008 の移流は、セル $i$ の運動量収支を次の形で求め、辺へ配っていました。

$$
\mathbf{M}_i = \sum_{l\in\partial i,\ s_{i,l} q_l < 0} s_{i,l}\, L_l\, q_l\left(\mathbf{u}_{k(i,l)} - \mathbf{u}_i\right), \qquad F u_j^n = u_j^n - \Delta t\,\frac{\left(\mathbf{M}_{1(j)}/A_{1(j)} + \mathbf{M}_{2(j)}/A_{2(j)}\right)\cdot\mathbf{n}_j}{h^\ast_{1(j)} + h^\ast_{2(j)}}
$$

増分は、セル中心の流速（Perot 法で再構成した $\mathbf{u}_i$、$\mathbf{u}_k$）だけで作られます。

検証ケース V07（こぶを越える跳水）を六角形配置で解いたところ、跳水の位置に横断方向の流れ（約 0.15 m/s。主流は約 2.4 m/s）が生じ、600 s 計算しても定常になりませんでした。時間刻みを 1/5 にしても変わらないので、空間の離散化の性質です。調べた結果は次のとおりです（一時的なテストで計算）。

- **最初の推定は誤りでした。** 側壁沿いのセルは五角形で、重心が母点からずれていると推定しました。しかし、ずれは格子幅の 0.004 倍しかなく、Perot 法の基準点を重心に変えても結果は変わりませんでした。
- **辺の流速に、セル中心の流速に現れない成分がたまっていました。** 両側のセルの流速の平均を法線へ射影した値と辺の流速との差（RMS）を比べました。正方形配置では約 0.01 m/s のまま一定でした。六角形配置では、0.006 m/s（25 s）から 0.32 m/s（125 s）まで増え続け、最大は 5 m/s に達しました。

六角形配置では、辺の数がセル数の約3倍あります。セル中心の流速（セルあたり2成分）は辺の流速のすべてを表せないので、Perot 法の再構成に現れない、格子規模の辺の流速の成分が存在します。ADR-0008 の移流はセル中心の流速だけで増分を作るので、この成分を下流へ運び去れません。跳水で生じた成分がその場にたまり、連続式の流量を通して横断方向の流れになっていました。正方形配置では、辺の数とセル数の比が小さく、この成分はほとんどありません。

## 決定

**移流の「自分の流速」を、セル中心の流速の法線成分 $\mathbf{u}_i\cdot\mathbf{n}_j$ から、辺の流速 $u_j$ に置き換えます。** 結果は、辺の流速を上流の流速へ近づける形になります。

$$
S_i = \sum_{l\in\partial i,\ s_{i,l} q_l < 0} \lvert L_l q_l\rvert, \qquad \mathbf{P}_i = \frac{1}{A_i}\sum_{l\in\partial i,\ s_{i,l} q_l < 0} \lvert L_l q_l\rvert\,\mathbf{u}_{k(i,l)}
$$

$$
\sigma_j = \Delta t\,\frac{S_{1(j)}/A_{1(j)} + S_{2(j)}/A_{2(j)}}{h^\ast_{1(j)} + h^\ast_{2(j)}}, \qquad \bar u_j = \frac{\left(\mathbf{P}_{1(j)} + \mathbf{P}_{2(j)}\right)\cdot\mathbf{n}_j}{S_{1(j)}/A_{1(j)} + S_{2(j)}/A_{2(j)}}
$$

$$
F u_j^n = u_j^n + \min(\sigma_j, 1)\left(\bar u_j - u_j^n\right)
$$

- $\bar u_j$ は、両側のセルに流れ込む水の流速の法線成分を、流入量で重み付けして平均した値です。
- **$\sigma_j \le 1$ の場合**：$F u_j^n = u_j^n - \Delta t\left[\sum_i (S_i/A_i)\,u_j^n - (\mathbf{P}_1 + \mathbf{P}_2)\cdot\mathbf{n}_j\right]/(h^\ast_1 + h^\ast_2)$ と同じです。保存形の移流 $\sum s L q\,\mathbf{u}_{\mathrm{up}} - u_j\sum s L q$ を流入側の辺で評価したもので、D-Flow FM の `iadv = 4`（Deltares, 2026 の Table 6.1）にあたります。
- **$\sigma_j > 1$ の場合**：時間刻みの条件を破った場合で、重みを 1 にして $F u_j^n = \bar u_j$ とします。D-Flow FM の `iadv = 6` の重み $\theta = \max(1 - 1/\sigma, 0)$ で陰的に扱った場合と同じ値です。
- **ADR-0008 から変えない点**：$h^\ast$（時刻 $n$ の流量で連続式を陽的に進めた水深）で割ること、両側のセルの重み（1/2 ずつ）、境界の扱い。

## 理由

### 格子規模の成分が運び去られる

各辺の流速そのものが、上流の流速へ $\sigma_j$ の割合で近づきます。そのため、セル中心の流速に現れない成分も、流れとともに下流へ運ばれます。

六角形配置の一様流に格子規模の乱れを乗せ、移流を5回繰り返すと、乱れは約 0.23 倍になりました。ADR-0008 の形では約 0.59 倍にしかなりません（`hydro` の単体テスト）。

### 跳水で Bélanger の式が成り立つ

ADR-0008 の「代替案」では、この形を「定常流で $S_i\,(u_j - \mathbf{u}_i\cdot\mathbf{n}_j)$ という保存形でない項が残り、跳水の共役水深がずれる」として退けました。**この判断は、1次元の定常流については誤りでした。**

1次元・単位幅・等間隔の格子の定常流では、どのセルでも $S_i/A_i = q/\Delta x$ です。追加される項を辺の運動量 $(h_1 + h_2)\Delta x/2$ で重み付けすると $q\left(u_{j-1} - 2u_j + u_{j+1}\right)/2$ になり、流速の2階差分の形をとります。2階差分は、辺について足し合わせると両端の差だけが残ります。そのため、両側の一様な区間では消え、ADR-0008 の理由のとおり、$q u + g h^2/2$ が離散式の上で保存されます。

両側の一様な区間の間に任意の遷移区間をはさんでも、両側の水深が Bélanger の式を満たせば釣り合いが丸め誤差の範囲で 0 になることを、`hydro` の単体テストで確かめています。

### 更新が有界になる

$F u_j^n$ は $u_j^n$ と $\bar u_j$ の凸結合です。そのため、辺の流速は、自分の流速と上流のセルの流速（法線成分）の範囲に収まります。ADR-0008 の安全策（増分を $1/\sigma_j$ 倍にする）は、重みを 1 で頭打ちにする自然な形になりました。

## 代替案

### 水平粘性を加える

C 格子のベクトルラプラシアン（セルの発散と頂点の渦度の勾配）で、格子規模の成分を減衰させる方法です。

- 利点：物理的な渦動粘性（overview 第8章の未決事項）と同じ形で入れられます。
- 欠点：係数の決め方が必要です。物理的な渦動粘性（たとえば $\kappa u_\ast h/6$）は、摩擦のない検証ケースでは 0 になり、効きません。

### 移流は ADR-0008 のままにし、六角形配置を使わない

- 利点：変更が要りません。
- 欠点：格子生成ツールの不規則なボロノイ格子も、辺の数がセル数の約3倍なので、同じ問題が起きる可能性があります。床止めの例題（V11）も六角形配置です。

### Perot 法の基準点を重心にする

上の「背景」のとおり、試しましたが効果がありませんでした。

### 辺の流速と、両側のセルの流速の平均（法線成分）との差だけを減衰させる

- 利点：セル中心の流速に現れない成分だけを狙えるように見えます。
- 欠点：この差は、解像された流速場でも2階差分として現れます。そのため、この決定と同じように解像された流速場にも数値粘性として働き、利点がありません。

## 結果

各ケースの値の詳細は [verification.md](../../verification.md) に記録しています。

- **V07（跳水）**：六角形配置でも定常になりました（横断方向の流速は 0.15 m/s から 0.013 m/s に下がりました）。そこで、合格基準に六角形配置を加えます。
  - 跳水の始まりが1セルぶん広くなり、格子幅 0.1 m の正方形配置では、跳水から 0.3 m 上流の水深の誤差が −1.6% から +2.1% になりました。
  - そのため、跳水の直前・直後の水深を確かめる位置を、跳水から 0.4 m（粗い格子の4セル分）に移しました。
- **V04（Thacker）**：誤差がわずかに増えました（1周期後の重心の誤差 0.091 → 0.095 m、3周期後 0.200 → 0.207 m）。合格基準は変えていません。
- **V05（ダム破壊）**：最も細かい格子での L1 誤差は、Stoker で 0.34% → 0.32%、Ritter で 0.48% → 0.53% と、ほとんど変わりませんでした。
- **V03・V06**：ADR-0008 と同じく基準を満たします。
- **運動量の総和の恒等式**：ADR-0008 の形で成り立っていた「辺の運動量の変化の総和がセルの運動量収支の総和に一致する」性質は、2次元では厳密には成り立たなくなります。単体テストは、1次元の定常跳水の釣り合いのテストに置き換えました。
